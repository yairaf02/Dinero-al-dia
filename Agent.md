# Agent Template – Dinero al Día

## Product
Build a modern personal finance web app called **Dinero al Día**.

## Goal
Help users understand where their money goes and calculate how much they can safely spend.

## Must-have features
- Input monthly income and savings goal
- Input spending by key categories
- Show total expenses, safe-to-spend amount, and a simple daily spending limit
- Show expense breakdown by category
- Validate user inputs and display clear feedback

## UX expectations
- Modern, clean, mobile-friendly UI
- Fast feedback on budget calculations
- Clear wording focused on financial clarity
